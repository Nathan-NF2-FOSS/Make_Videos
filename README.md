# Video Creator

A simple Python script that creates a short video from a static image and background music using `moviepy`.

This project is useful for making quick slideshow-style videos, looping visuals with audio, or generating simple media previews from a single image and soundtrack.

## Features

- Load an image and set its display duration
- Load an audio track and trim it to match the video length
- Combine image + audio into a single MP4 video
- Easy to customize for different image/audio inputs and durations
